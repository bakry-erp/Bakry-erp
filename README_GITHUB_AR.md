# معرض البكري ERP

نسخة GitHub Pages متوافقة مع الهاتف والكمبيوتر.

## النشر
1. ارفع محتويات المجلد إلى جذر المستودع `main` (بما فيها index.html ومجلدات css وjs وfonts وwebfonts وicons).
2. من Settings > Pages اختر Deploy from a branch ثم `main` و`/(root)` ثم Save.
3. افتح رابط GitHub Pages.

## التخزين
البيانات تحفظ محلياً داخل IndexedDB في المتصفح على نفس الجهاز والمتصفح. لا يوجد اتصال بخادم قاعدة بيانات في هذه النسخة. استخدم تصدير قاعدة البيانات من الإعدادات وخذ نسخة احتياطية دورياً. البيانات لا تتزامن تلقائياً بين الهاتف والكمبيوتر؛ يلزم تصدير/استيراد نسخة احتياطية لنقلها.
