# معرض البكري ERP — نسخة GitHub Pages

## النشر على GitHub Pages
1. سجّل الدخول إلى GitHub وأنشئ مستودعًا جديدًا باسم `bakry-erp`.
2. اجعل المستودع **Private** إن كان حسابك يسمح بذلك؛ لا تضع بيانات عملاء حقيقية أو نسخ قواعد البيانات في GitHub مطلقًا.
3. ارفع **محتويات هذا المجلد** إلى جذر المستودع (ملف `index.html` يجب أن يكون في الجذر).
4. من Settings ثم Pages اختر `Deploy from a branch`، والفرع `main` والمجلد `/ (root)` ثم Save.
5. انتظر حتى يظهر رابط الموقع في صفحة Pages وافتحه من الهاتف والكمبيوتر.
6. على الهاتف: من Chrome افتح الرابط ثم قائمة ⋮ ثم `إضافة إلى الشاشة الرئيسية` أو `تثبيت التطبيق`.

## التشغيل دون إنترنت
افتح الرابط أول مرة مع الإنترنت وانتظر اكتمال التحميل، ثم أعد فتحه مرة أخرى. عامل الخدمة يخزّن ملفات الواجهة للعمل دون اتصال.

## مهم جدًا بشأن البيانات
- هذه النسخة تستخدم قاعدة بيانات المتصفح المحلية (IndexedDB). البيانات التي تدخلها على الهاتف **لا تتزامن تلقائيًا** مع الكمبيوتر، والعكس صحيح.
- GitHub Pages يستضيف ملفات الموقع فقط، وليس قاعدة بيانات مشتركة أو خادمًا خلفيًا.
- لا ترفع ملفات النسخ الاحتياطي أو بيانات العملاء/الأرقام القومية إلى مستودع GitHub، حتى لو كان عامًا.
- خذ نسخة احتياطية من داخل البرنامج بانتظام، واختبر الاستيراد والتصدير على بيانات تجريبية أولًا.
- بعض إعدادات النسخ الاحتياطي/الخادم الموجودة في البرنامج الأصلي تحتاج Backend ولن تعمل عبر GitHub Pages وحده.
