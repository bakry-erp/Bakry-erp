# معرض البكري ERP — تحسين تنسيق الموبايل واستعادة إطارات البطاقات

## ما تم تغييره في هذه النسخة
- `css/bakry-light-cards.css`: استعادة خلفيات البطاقات البيضاء مع إطارات رفيعة وهادئة بدرجات أزرق وأحمر باهتة، مع ظلال خفيفة. تم تجنب الحدود الزرقاء والحمراء المشبعة على كل بطاقة، مع الإبقاء على ألوان الحالات والتنبيهات والأزرار بوضوح.
- `css/bakry-mobile-polish.css` **(ملف جديد)**: إنشاء ترتيب خاص للشاشات الصغيرة مع الحفاظ على نفس البيانات والوظائف؛ ضغط الهيدر، إعادة توزيع النماذج والبطاقات في عمود واحد، معالجة الأعمدة التي كانت تخرج خارج الشاشة، وإظهار الجداول العريضة داخل حاويات تمرير أفقي.
- `index.html`: ربط ملف تنسيق الموبايل الجديد، وإعادة ترتيب واجهة الموبايل بصريًا عبر CSS دون حذف حقول البيانات. تم إزالة عنصر صورة الشعار وخيارات رفعه من الواجهة، مع الإبقاء على أيقونة الموتوسيكل.
- `js/app.js`: تعطيل الاعتماد على صورة الشعار القديمة وجعل قيمة الشعار المحفوظة فارغة حتى لا يعاد استدعاؤها من إعدادات سابقة.
- `sw.js`: تحديث اسم ذاكرة التخزين المؤقت إلى `bakry-erp-local-v8` وإضافة ملف التنسيق الجديد إلى ملفات التشغيل الأساسية.
- `images/bakry-logo.jpg` ومجلد `images/`: حذف صورة الشعار القديمة بعد إزالة مراجعها المرئية.

## إصلاح موضع اختيار البيع النقدي أو التقسيط
اختيار «نقدي (كاش) / بيع بالتقسيط» وطريقة السداد وسعر البيع كانت موجودة في HTML داخل بطاقة الملخص المالي، لكن البطاقة كانت في عمود جانبي مستقل. عند عرضها على الهاتف ظل تخطيط العمودين قائمًا، فكانت البطاقة تضيق أو تقع خارج عرض الجهاز. تم جعل تخطيط صفحة البيع عمودًا واحدًا على الهاتف، لتظهر بطاقة «بيانات السداد والمالية» كاملة أسفل بيانات العميل والمركبة، دون إنشاء نسخة ثانية من الحقول أو تغيير منطق حفظ الفاتورة.

## فحص الواجهات
تم فحص تخطيط الصفحات الموجودة في ملف HTML عند عروض 390 و360 و768 بكسل، وكذلك عرض سطح المكتب 1365 بكسل. لم تظهر عناصر نماذج أو بطاقات خارج حدود العرض في الفحص؛ الجداول التي تتجاوز عرض الهاتف تبقى داخل حاويات قابلة للسحب أفقيًا. تم فحص ظهور بطاقة السداد في تخطيط صفحة المبيعات على الهاتف.

هذا الفحص البصري محلي لملفات HTML/CSS؛ لم يتم نشر التغييرات إلى GitHub Pages، ولم يُجر اختبار تشغيل حي شامل لقاعدة البيانات وتدفقات الحفظ والطباعة على جهاز فعلي. يجب إجراء اختبار نهائي بعد رفع النسخة إلى المستودع.

## النشر على GitHub Pages
1. خذ نسخة احتياطية من قاعدة البيانات من داخل النظام قبل النشر.
2. ارفع محتويات المجلد إلى جذر مستودع `Bakry-erp` على فرع `main` مع استبدال الملفات الموجودة.
3. تأكد من حذف `images/bakry-logo.jpg` من المستودع إذا كان موجودًا في نسختك السابقة.
4. استخدم رسالة Commit:
   `تحسين واجهة الموبايل واستعادة إطارات البطاقات وإظهار خيارات البيع`
5. بعد اكتمال النشر، أغلق تبويب الموقع على الهاتف وافتحه مجددًا أو نفّذ تحديثًا كاملاً حتى يتم تحميل ملفات CSS الجديدة.

## تنبيه التخزين
تُحفظ البيانات في `IndexedDB` داخل المتصفح وعلى الجهاز نفسه. لا توجد مزامنة تلقائية بين الهاتف والكمبيوتر. خذ نسخة احتياطية قبل استبدال الملفات، ولا ترفع بيانات العملاء أو الأرقام القومية إلى مستودع GitHub عام.

## تحديث إضافي — إصلاح واجهة الموبايل والثيمات والاحتفاظ بالصفحة

### التعديلات المضافة في هذه النسخة
- إصلاح تخطيط نافذة **تعديل فاتورة البيع**: ضبط الشبكات الداخلية وعرض الحقول والضامنين والتنبيهات داخل حدود النافذة، مع ترتيب عمودي مناسب للموبايل والإبقاء على عمودين في الشاشات الواسعة.
- ضبط بطاقات **الخزينة والمحاسبة المالية** على الموبايل لتظهر بطاقة الخزينة ثم الإيرادات والمصروفات وصافي الأرباح بشكل مقروء.
- إعادة عرض تفاصيل تنبيهات العميل/الضامن السابقة في عمود واحد على الهاتف حتى لا تختفي قيمة التاريخ أو تفاصيل الجدول خارج الإطار.
- ضبط زر القائمة الجانبية في الموبايل على بداية صف الهيدر وإلغاء الإزاحة الرأسية السابقة.
- الاحتفاظ باسم الصفحة الأخيرة في `location.hash` وفي `localStorage`، واستعادة الصفحة المحفوظة بعد تحديث المتصفح بدل الرجوع الإجباري إلى لوحة التحكم. يظل التحويل إلى لوحة التحكم مقصودًا عند تسجيل الدخول الجديد أو تغيير فئة المستخدم يدويًا.
- إلغاء قائمة المتصفح التي تظهر بالنقر بزر الفأرة الأيمن داخل واجهة النظام.
- الإبقاء على الثيم الأبيض كما هو في طبقة الإصلاح الجديدة، واستبدال خيارات الألوان القديمة بخيارين جديدين: **دارك** و**أزرق وذهبي**، مع كتابة فاتحة وتنسيق متناسق لعناصر الواجهة.
- نقل إعداد الثيمات القديمة المحفوظة تلقائيًا إلى الثيم الأبيض عند أول تحميل، حتى لا يبقى اختيار قديم غير موجود في القائمة.

### الملفات المتغيرة
- `index.html`: قائمة الثيمات الجديدة، تحميل ملف CSS الإضافي، تحديث إصدار `app.js`، وإلغاء قائمة النقر الأيمن.
- `js/app.js`: اعتماد الثيمات الثلاثة الجديدة/المعتمدة، ترحيل إعدادات الألوان القديمة إلى الأبيض، واستعادة الصفحة الأخيرة بعد إعادة التحميل.
- `sw.js`: رفع رقم ذاكرة التخزين المؤقت وإضافة ملف CSS الجديد إلى قائمة الملفات الأساسية.
- `README_GITHUB_AR.md`: توثيق التعديلات الإضافية.

### ملف جديد
- `css/bakry-requested-fixes.css`: إصلاحات نافذة تعديل الفاتورة والمحاسبة والتنبيهات والزر، بالإضافة إلى ألوان الثيمين الجديدين.

### ملفات محذوفة
- لا توجد ملفات محذوفة في هذا التحديث.

### فحوصات التنفيذ
- اجتاز `node --check` ملفي `js/app.js` و`sw.js` دون أخطاء صياغة.
- اجتاز ملف CSS الجديد فحص التحليل النحوي دون أخطاء.
- تمت مراجعة وجود اختيارات الثيمات الثلاثة فقط في HTML ومطابقة أسمائها مع منطق JavaScript.
- لم يتم إجراء اختبار بصري مباشر داخل متصفح فعلي، ولم يتم نشر الملفات إلى GitHub Pages. لذلك يلزم اختبار الواجهات على الهاتف والكمبيوتر بعد رفع النسخة، خصوصًا نافذة تعديل الفاتورة وحفظها فعليًا.

### ملاحظة مهمة بخصوص حماية السورس كود
تم إلغاء قائمة النقر بزر الفأرة الأيمن داخل الموقع فقط. هذا إجراء شكلي لا يمنع الوصول إلى ملفات HTML وCSS وJavaScript؛ لأن المتصفح يحتاج إلى تنزيل هذه الملفات وتشغيلها، ويمكن الوصول إليها من أدوات المطور أو تبويب الشبكة أو طلب الملفات مباشرة. وبما أن الموقع مستضاف كواجهة ثابتة على GitHub Pages، فلا يمكن جعل كود الواجهة سرّيًا أو منع كل شخص من الاطلاع عليه. لا تضع كلمات مرور أو مفاتيح أو بيانات عملاء داخل ملفات الواجهة أو مستودع عام. الحماية الحقيقية للعمليات والبيانات الحساسة تتطلب خادمًا خلفيًا بصلاحيات وتحقق على الخادم، وليس تعطيل قائمة النقر الأيمن.
