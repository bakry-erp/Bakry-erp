# معرض البكري ERP — النسخة المصححة

## الملفات التي تم تحديثها
- `index.html`: إصلاح التنقل واستعادة الصفحة من الرابط، إضافة صفحة تقرير التعثر، وضبط اسم المعرض وزر القائمة.
- `js/app.js`: حماية عرض تقرير التعثر مع الإبقاء على التحصيل الجماعي وإصلاح حفظ بيانات الشاسيه/الموتور عند حذف الفاتورة.
- `js/db.js`: ترقية آمنة لمخطط IndexedDB إلى الإصدار 3 للتأكد من إنشاء أي جدول محلي ناقص دون حذف الجداول الموجودة.
- `css/mobile.css`: تصميم القائمة الجانبية البيضاء، زر الموبايل الأصفر، وتحسين استجابة الشاشات الصغيرة.
- `sw.js`: تحديث رقم ذاكرة التخزين المؤقت لإجبار المتصفح على تحميل النسخة الجديدة.

## النشر على GitHub Pages
1. خذ نسخة احتياطية من قاعدة البيانات من داخل النظام قبل النشر.
2. ارفع محتويات هذا المجلد إلى جذر مستودع `Bakry-erp` على فرع `main`، واختر استبدال الملفات القديمة عند الطلب.
3. احذف الملف القديم `css/bakry-refined.css` من المستودع؛ تم دمج تنسيقاته المطلوبة في `css/mobile.css` لتجنب الاعتماد على ملف إضافي قد لا يتم رفعه.
4. استخدم رسالة Commit: `إصلاح القائمة الجانبية وتقرير التعثر وتحسين توافق الموبايل`.
5. بعد اكتمال GitHub Pages، افتح الموقع في المتصفح ثم أعد تحميله تحديثاً كاملاً. على الهاتف أغلق تبويب الموقع وافتحه من جديد؛ وإذا استمر عرض النسخة القديمة امسح بيانات الموقع المؤقتة من إعدادات المتصفح.

## تنبيه التخزين
تُحفظ البيانات في `IndexedDB` داخل المتصفح وعلى الجهاز نفسه. لا توجد مزامنة تلقائية بين الهاتف والكمبيوتر. خذ نسخة احتياطية قبل استبدال الملفات، ولا ترفع بيانات العملاء أو الأرقام القومية إلى مستودع GitHub عام.
