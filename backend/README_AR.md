# واجهة Bakry ERP الخلفية — مرحلة تأسيس آمنة

هذه حزمة Backend أولية لتجهيز PostgreSQL. لا تضع DATABASE_URL داخل ملفات الواجهة أو GitHub Pages؛ يوضع السر في متغيرات بيئة خدمة الخادم فقط.

## التشغيل
1. أنشئ خدمة Node.js على استضافة تدعم Node 20 أو أحدث.
2. انسخ متغيرات `DATABASE_URL` و`APP_ORIGIN` من `.env.example` إلى إعدادات الخدمة السرية.
3. نفّذ `schema.sql` مرة واحدة على قاعدة `bakryerp` بعد التأكد من النسخة الاحتياطية.
4. ثبّت الاعتمادات بـ `npm install` ثم شغّل `npm start`.
5. اختبر `GET /api/health`.

## حدود هذه المرحلة
- هذه ليست نسخة جاهزة للنشر العام: لا يوجد تسجيل دخول/مصادقة بعد، لذلك يجب عدم إتاحتها للعامة قبل إضافة المصادقة وتقييد CORS.
- مخزن JSONB المرن مقصود كطبقة انتقال أولى؛ لا يثبت وحده علاقات الجداول أو قيود المحاسبة.
- لم يتم توصيل الواجهة به بعد. يجب أولًا إضافة هوية UUID مستقرة لكل سجل، ثم تعديل MotoDB adapter مع طابور IndexedDB واختبار ترحيل بيانات محلية فعلية.
- يجب ألا تُحذف العمليات المحلية إلا بعد تأكيد الخادم، ويجب استخدام UUID للعملية لمنع التكرار.
