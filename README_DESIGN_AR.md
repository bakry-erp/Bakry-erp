# تحديث هوية وتصميم معرض البكري

- الوضع الداكن: كحلي ملكي مع الذهبي.
- الوضع النهاري: أبيض مع الأزرق والذهبي (يُختار من خيار Emerald/الوضع النهاري داخل الإعدادات).
- طبقة تصميم متجاوبة للموبايل والكمبيوتر.
- زر قائمة جانبية للموبايل مع إغلاق بالنقر خارج القائمة.
- تحسين التباين والحقول والأزرار والجداول والنوافذ المنبثقة.

هذا تحديث واجهة فقط. لا يُعد إصلاحًا لخادم قاعدة البيانات أو مزامنة البيانات بين الأجهزة. GitHub Pages يستضيف الواجهة الثابتة فقط.
